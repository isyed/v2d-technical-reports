Author: Ismail Syed. University of Texas at Austin / [longhorizon.bot](https://www.longhorizon.bot). Contact: syedim@gmail.com.

- [Track 2: robotic grounding — two-page report](track2/report.pdf)
- [Track 1: reconstruction — two-page report](track1/report.pdf)

Both use the supplied unmodified NVIDIA extended-abstract class and include Introduction, Approach, Experiments & Results, Conclusion and the four Industry Innovation judging areas.

The reports identify selected leaderboard files, not an assertion of completed organizer container validation. The implementation repositories are separate: [Track 2](https://github.com/isyed/v2d-grounding), [Track 1](https://github.com/isyed/v2d-reconstruction), and [reusable modules](https://github.com/isyed/real2sim2real).

Build with Tectonic (`tectonic report.tex`) or pdflatex/BibTeX in each report directory. Original template copyright notices are preserved. These reports contain no video, dataset, credential or model-weight files.
